# 二叉树算法题

二叉树是 LeetCode 中最核心的数据结构之一。大量中等和困难题都与二叉树相关。与链表相比，二叉树的核心难点不在于指针操作，而在于 **递归思想、树的结构理解以及遍历方式的灵活应用**。

大多数二叉树题目本质上都可以归类为 **遍历问题、递归问题或结构变换问题**。掌握这些基础套路后，大部分题目都可以通过模板进行变形解决。

下面是一篇 **结构紧凑、适合算法博客、面向 LeetCode 的二叉树知识点总结**，整体风格和你之前要求的链表博客一致，不拆太多小点，重点放在算法套路。

## 一、二叉树基础结构

LeetCode 中二叉树通常定义为：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

每个节点包含三个部分：

- 当前节点值
- 指向左子树的指针
- 指向右子树的指针

与链表不同，二叉树具有 **分叉结构**，因此算法通常围绕 **递归处理左右子树** 展开。

## 二、二叉树遍历

遍历是所有二叉树问题的基础。二叉树一共有四种常见遍历方式：

前序遍历、中序遍历、后序遍历、层序遍历。

### 前序遍历

顺序：因为 root 在最前面，所以叫前序

```text
根 -> 左 -> 右
先访问根节点，再访问子树
    1
   / \
  2   3
# 1 2 3 
```

递归写法：

```cpp
void preorder(TreeNode* root) {
    if (root == nullptr) return;

    cout << root->val;
    preorder(root->left);
    preorder(root->right);
}
```

前序遍历常用于：

- 复制树
- 序列化树
- 构建树

典型题：

- 144 Binary Tree Preorder Traversal

### 中序遍历

顺序：（因为 **root 在中间**，所以叫：中序）

```text
左 -> 根 -> 右
```

递归写法：

```cpp
void inorder(TreeNode* root) {
    if (root == nullptr) return;

    inorder(root->left);
    cout << root->val;
    inorder(root->right);
}
```

中序遍历有一个重要性质：

**对于二叉搜索树，中序遍历结果是递增序列。**

典型题：

- 94 Binary Tree Inorder Traversal
- 98 Validate Binary Search Tree

### 后序遍历

顺序：

```text
左 -> 右 -> 根
```

递归写法：

```cpp
void postorder(TreeNode* root) {
    if (root == nullptr) return;

    postorder(root->left);
    postorder(root->right);
    cout << root->val;
}
```

后序遍历常用于：

- 删除树
- 计算树信息
- 动态规划

典型题：

- 145 Binary Tree Postorder Traversal
- 543 Diameter of Binary Tree

### 层序遍历

层序遍历是按层访问节点，需要借助队列。

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (!root) return result;

    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int size = q.size();
        vector<int> level;

        for (int i = 0; i < size; i++) {
            TreeNode* node = q.front();
            q.pop();

            level.push_back(node->val);

            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }

        result.push_back(level);
    }

    return result;
}
```

典型题：

- 102 Binary Tree Level Order Traversal
- 199 Binary Tree Right Side View

## 三、递归思想

二叉树问题最重要的思想是：

```text
把问题拆成左右子树的同类问题
```

递归模板通常是：

```cpp
int dfs(TreeNode* root) {
    if (root == nullptr) return base;

    int left = dfs(root->left);
    int right = dfs(root->right);

    return combine(left, right);
}
```

很多题都符合这个模板。

典型例子：

计算树高度：

```cpp
int maxDepth(TreeNode* root) {
    if (!root) return 0;

    return max(maxDepth(root->left), maxDepth(root->right)) + 1;
}
```

典型题：

- 104 Maximum Depth of Binary Tree

## 四、二叉树路径问题

路径类问题是 LeetCode 高频题型。

常见问题包括：

- 根到叶路径
- 最大路径和
- 路径总和

### 根到叶路径

典型题：

- 112 Path Sum
- 257 Binary Tree Paths

例如判断是否存在路径和：

```cpp
bool hasPathSum(TreeNode* root, int targetSum) {
    if (!root) return false;

    if (!root->left && !root->right) {
        return targetSum == root->val;
    }

    return hasPathSum(root->left, targetSum - root->val) ||
           hasPathSum(root->right, targetSum - root->val);
}
```

### 最大路径和

典型题：

- 124 Binary Tree Maximum Path Sum

思路：

后序遍历计算左右贡献。

```cpp
int maxSum = INT_MIN;

int dfs(TreeNode* root) {
    if (!root) return 0;

    int left = max(0, dfs(root->left));
    int right = max(0, dfs(root->right));

    maxSum = max(maxSum, root->val + left + right);

    return root->val + max(left, right);
}
```

## 五、二叉搜索树

二叉搜索树（BST）具有特殊性质：

```text
左子树所有节点 < 根节点
右子树所有节点 > 根节点
```

利用这个性质可以解决很多问题。

典型题：

- 98 Validate Binary Search Tree
- 230 Kth Smallest Element in BST
- 700 Search in a Binary Search Tree

例如验证 BST：

```cpp
bool isValidBST(TreeNode* root, long long low, long long high) {
    if (!root) return true;

    if (root->val <= low || root->val >= high) return false;

    return isValidBST(root->left, low, root->val) &&
           isValidBST(root->right, root->val, high);
}
```

## 六、构建二叉树

根据遍历序列构建树也是常见题型。

常见组合：

- 前序 + 中序
- 中序 + 后序

典型题：

- 105 Construct Binary Tree from Preorder and Inorder Traversal
- 106 Construct Binary Tree from Inorder and Postorder Traversal

核心思想：

- 前序确定根
- 中序确定左右子树范围

示例：

```cpp
TreeNode* build(vector<int>& preorder, int pl, int pr,
                vector<int>& inorder, int il, int ir,
                unordered_map<int,int>& index) {

    if (pl > pr) return nullptr;

    int rootVal = preorder[pl];
    TreeNode* root = new TreeNode(rootVal);

    int k = index[rootVal];
    int leftSize = k - il;

    root->left = build(preorder, pl + 1, pl + leftSize,
                       inorder, il, k - 1, index);

    root->right = build(preorder, pl + leftSize + 1, pr,
                        inorder, k + 1, ir, index);

    return root;
}
```

## 七、最近公共祖先

典型题：

- 236 Lowest Common Ancestor of a Binary Tree

思路：

如果当前节点是 p 或 q，直接返回。

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;

    TreeNode* left = lowestCommonAncestor(root->left, p, q);
    TreeNode* right = lowestCommonAncestor(root->right, p, q);

    if (left && right) return root;

    return left ? left : right;
}
```

## 八、二叉树常见套路总结

遍历类问题

- 前序遍历
- 中序遍历
- 后序遍历
- 层序遍历

递归问题

- 树高度
- 节点数量
- 结构判断

路径问题

- 路径和
- 最大路径

二叉搜索树

- 验证 BST
- 查找节点
- 第 k 小元素

树结构变换

- 构建树
- 合并树
- 翻转树


## 总结

二叉树问题的核心不在于复杂数据结构，而在于 **递归思维和遍历方式的理解**。大部分题都可以通过以下步骤解决：

1. 选择合适遍历方式
2. 明确递归返回值含义
3. 在左右子树结果基础上计算当前节点结果

掌握这些基本套路后，大部分 LeetCode 二叉树题都可以通过模板进行变形解决。
