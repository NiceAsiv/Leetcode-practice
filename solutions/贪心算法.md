# 贪心算法题

贪心算法是 LeetCode 中非常常见的一类算法思想。它不像动态规划那样枚举所有状态，也不像回溯那样尝试所有可能，而是**每一步都做出当前看起来最优的选择**，希望通过局部最优最终达到全局最优。

与二叉树、链表这种“数据结构型”题目不同，贪心更偏向一种**策略思想**。它的难点通常不在代码实现，而在于：

\- 你能不能看出这题可以贪心
\- 你设计的局部最优策略是否正确
\- 你能不能证明局部最优可以推出全局最优



## 一、贪心算法基础思想

贪心算法的核心思想是：

每一步都选择当前最优解

也就是：

局部最优 -> 希望得到全局最优

例如找零钱问题：

```
金额：41
硬币：25，10，5，1
```

贪心做法就是每次优先拿最大面额：

```
41 -> 25 -> 剩16
16 -> 10 -> 剩6
6 -> 5 -> 剩1
1 -> 1
```

最终用了 4 枚硬币

## 二、贪心算法适用条件

一个问题想要用贪心，通常需要满足两个重要性质。

也就是：

```
每一步做出的局部最优选择，不会破坏最终得到全局最优解
```

简单说就是：

- 当前选这个，看起来最优
- 以后不会因为这一步选错而导致整体变差

这是贪心成立的关键。

例如活动选择问题中：

- 每次优先选**结束时间最早**的活动

这个局部选择可以保证后面留下尽可能多的时间安排其他活动，所以是正确的贪心策略。

## 三、贪心算法常见解题步骤

贪心题通常可以按下面这个流程来思考。

### 1. 先观察局部最优策略

先问自己：

- 每一步应该优先选什么
- 是选最大的，最小的，最早结束的，还是最便宜的
- 当前最优选择会不会影响后续结果

常见策略有：

- 优先选右端点最小
- 优先选结束时间最早
- 优先选数值最大
- 优先选代价最小
- 优先选当前能覆盖最多范围的方案

### 2. 排序

很多贪心题第一步都是排序。

因为排序后，局部最优策略才容易实施。

常见排序方式：

- 按左端点排序
- 按右端点排序
- 按数值从大到小排序
- 按代价从小到大排序
- 按利润 / 权重排序

所以很多时候一看到题目，就可以先想：

### 3. 遍历并做选择

排序后，通常就是线性扫描：

```
for (每个元素) {
    if (满足条件) {
        选择它
    } else {
        跳过它
    }
}
```

### 4. 维护答案或状态

在遍历过程中维护：

- 当前答案
- 当前覆盖范围
- 当前可用资源
- 当前边界位置

这就是大多数贪心题的基本框架。

## 四、贪心算法常见类型

贪心题在 LeetCode 中大致可以分成几类。

### 区间问题

这类题是最经典的贪心题型。

常见做法：

- 按右端点排序
- 按左端点排序
- 维护当前覆盖边界

典型题：

- 435 Non-overlapping Intervals
- 452 Minimum Number of Arrows to Burst Balloons
- 55 Jump Game
- 45 Jump Game II

### 最值选择问题

每次选当前最优的最大值或最小值。

典型题：

- 455 Assign Cookies
- 1005 Maximize Sum Of Array After K Negations

### 资源分配问题

有限资源如何尽量分配给更多对象，或者得到最大收益。

典型题：

- 134 Gas Station
- 135 Candy
- 406 Queue Reconstruction by Height

### 构造最优解问题

不是直接求值，而是构造一个满足条件且最优的方案。

典型题：

- 763 Partition Labels
- 738 Monotone Increasing Digits

## 五、区间类贪心

区间类问题是贪心算法最重要的一类。

很多题的关键结论都是：

```
按右端点排序
```

因为右端点越小，越可能给后续留下更多空间。

### 不重叠区间

典型题：

- 435 Non-overlapping Intervals

目标是删除最少区间，使剩下区间互不重叠。

等价理解：

```
选择最多的不重叠区间
```

贪心策略：

```
优先选择右端点最小的区间
```

代码模板：

```
int eraseOverlapIntervals(vector<vector<int>>& intervals) {
    if (intervals.empty()) return 0;

    sort(intervals.begin(), intervals.end(), [](auto& a, auto& b) {
        return a[1] < b[1];
    });

    int count = 1;
    int end = intervals[0][1];

    for (int i = 1; i < intervals.size(); i++) {
        if (intervals[i][0] >= end) {
            count++;
            end = intervals[i][1];
        }
    }

    return intervals.size() - count;
}
```

### 用最少箭引爆气球

典型题：

- 452 Minimum Number of Arrows to Burst Balloons

这题本质和区间选择非常像。

如果两个气球区间有交集，那么一支箭可以同时射爆。

贪心策略仍然是：

```
按右端点排序
```

然后尽量让一支箭覆盖更多后续区间。

## 六、跳跃类贪心

跳跃游戏也是非常经典的一类贪心题。

### 跳跃游戏 I

典型题：

- 55 Jump Game

题意是判断能不能跳到最后一个位置。

关键贪心思想：

```
实时维护当前最远可以到达的位置，从而找到一个地方连续到达（连续可达才可达）
```

如果当前位置已经超过最远可达位置，说明到不了。

代码：

```
bool canJump(vector<int>& nums) {
    int farthest = 0;

    for (int i = 0; i < nums.size(); i++) {
        if (i > farthest) return false;
        farthest = max(farthest, i + nums[i]);
    }

    return true;
}
```

### 跳跃游戏 II

典型题：

- 45 Jump Game II

要求最少跳几次到终点。

这里仍然是贪心，但比上一题多一层“分层”思想。

核心做法：

- `curEnd` 表示当前这一步跳跃最远能到哪里
- `farthest` 表示在当前区间内，下一步最远能到哪里
- 当扫描到 `curEnd` 时，必须跳一次

代码：

```
int jump(vector<int>& nums) {
    int ans = 0;
    int curEnd = 0;
    int farthest = 0;

    for (int i = 0; i < nums.size() - 1; i++) {
        farthest = max(farthest, i + nums[i]);
        if (i == curEnd) {
            ans++;
            curEnd = farthest;
        }
    }

    return ans;
}
```

## 七、数组与资源分配类贪心

### 分发饼干

典型题：

- 455 Assign Cookies

思路：

- 小饼干优先满足小胃口
- 或者大饼干优先匹配大胃口
- 本质是排序后双指针贪心匹配

代码：

```
int findContentChildren(vector<int>& g, vector<int>& s) {
    sort(g.begin(), g.end());
    sort(s.begin(), s.end());

    int i = 0, j = 0;
    int ans = 0;

    while (i < g.size() && j < s.size()) {
        if (s[j] >= g[i]) {
            ans++;
            i++;
            j++;
        } else {
            j++;
        }
    }

    return ans;
}
```

### 加油站

典型题：

- 134 Gas Station

这题的关键结论很经典。

如果总油量小于总消耗，肯定无法绕一圈。

如果总油量足够，那么可以通过贪心找到起点。

核心思路：

- 总和判断能否完成
- 当前油量一旦小于 0，说明之前起点不行
- 下一位置作为新的起点

代码：

```
int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
    int total = 0;
    int cur = 0;
    int start = 0;

    for (int i = 0; i < gas.size(); i++) {
        total += gas[i] - cost[i];
        cur += gas[i] - cost[i];

        if (cur < 0) {
            start = i + 1;
            cur = 0;
        }
    }

    return total >= 0 ? start : -1;
}
```

## 八、贪心与动态规划的区别

贪心和动态规划很容易混。

它们的区别在于：

### 贪心

```
每一步只看当前，直接做局部最优选择
```

不回头，不枚举所有可能。

### 动态规划

```
考虑所有状态转移，从整体上求全局最优
```

会系统比较不同决策带来的结果。

最经典的例子就是背包问题。

### 分数背包

可以贪心。

因为物品可以拆分，所以总是优先选单位价值最高的。

### 0/1 背包

不能贪心。

因为一个物品只能选或不选，局部最优不一定导致整体最优，所以通常要用动态规划。

所以判断时可以先问：

```
局部最优能不能稳定推出全局最优
```

如果不能，就要考虑动态规划。

## 九、贪心算法常见证明思路

贪心最难的部分通常不是实现，而是证明。

常见证明方法有三种。

### 交换论证

这是最常见的方法。

思路是：

- 假设最优解不是按照你的贪心策略选的
- 那就把它替换成贪心选择
- 替换后答案不会更差
- 所以贪心选择也可以出现在某个最优解中

区间问题里经常这样证明。

### 反证法

假设贪心策略不对，推出矛盾。

### 数学归纳法

证明前 k 步贪心都成立，再推出第 k+1 步也成立。

## 十、贪心算法常见模板

很多贪心题代码都长得很像。

### 排序 + 选择

```
sort(nums.begin(), nums.end(), cmp);

for (auto& x : nums) {
    if (满足条件) {
        选择它;
    }
}
```

### 维护最远边界

```
int farthest = 0;
for (int i = 0; i < nums.size(); i++) {
    farthest = max(farthest, i + nums[i]);
}
```

### 双指针匹配

```
sort(a.begin(), a.end());
sort(b.begin(), b.end());

int i = 0, j = 0;
while (i < a.size() && j < b.size()) {
    if (可以匹配) {
        i++;
        j++;
    } else {
        j++;
    }
}
```

## 十一、贪心算法常见套路总结

区间问题

- 按右端点排序
- 优先保留结束更早的区间
- 维护当前边界

跳跃问题

- 维护当前最远可达位置
- 维护当前层的边界

匹配问题

- 排序
- 双指针
- 小的先匹配小的，或者大的先匹配大的

构造问题

- 每一步尽量让当前答案最优
- 同时保证后续仍然合法

资源分配问题

- 优先满足代价更小或收益更高的对象
- 保证局部决策不会浪费资源

## 案例

### [121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

维护一个股票价格，只能卖一次

方案：

- 遍历过程中维护历史最低价格

- 在每一天尝试“如果今天卖出，利润是多少”

- 不断更新最大利润

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if(prices.size()==0) return 0;
        int ans = 0;
        int minPrice = INT_MAX ;
        for(int price: prices){
            minPrice = min(minPrice,price);
            ans = max(ans,price-minPrice);
        }
        return ans;
    }
};
```
