# 排序方法

## C++ 标准库排序 sort

### 最常用：`std::sort`

头文件：

```cpp
#include <algorithm>
```

用法：

```cpp
sort(v.begin(), v.end());                 // 升序
sort(v.begin(), v.end(), greater<int>()); // 降序
```

适用容器：随机访问迭代器（`vector`, `deque`, `array`，不适用于 `list`）

时间复杂度：平均/最坏基本视作 **O(n log n)**（实现通常是 introsort：快排+堆排+插排混合）
 空间复杂度：**O(log n)**（递归栈）

### 自定义比较（面试高频）

按结构体/二维数组/pair 的某个字段排序：

```cpp
sort(a.begin(), a.end(), [](const auto& x, const auto& y){
    return x[0] < y[0];          // 按第一列升序
});
```

pair 常用：

```cpp
sort(v.begin(), v.end(), [](const pair<int,int>& p1, const pair<int,int>& p2){
    if(p1.first != p2.first) return p1.first < p2.first;
    return p1.second < p2.second;
});
```

比较函数必须满足“严格弱序”（不然会出现未定义行为），简单记：
 **不要写 `<=`，要写 `<`，相等时返回 false。**

## 稳定排序 stable_sort

### 什么是稳定

稳定排序：如果两个元素“排序关键字相同”，排序后它们的相对顺序不变。

例子：按成绩排序，成绩相同的同学希望保持原来的先后。

### C++ 用法

```cpp
stable_sort(v.begin(), v.end(), cmp);
```

复杂度：通常 **O(n log n)**
空间：通常需要额外内存（比 sort 更“贵”）

## 基础排序方法

### 冒泡排序 Bubble Sort

思路：相邻比较交换，每一趟把最大值“冒”到末尾。

- 平均/最坏：O(n²)
- 最好（已排序+优化）：O(n)
- 空间：O(1)
- 稳定：稳定

代码（带优化）：

```
void bubbleSort(vector<int>& a){
    int n = a.size();
    for(int i=0;i<n-1;i++){
        bool swapped=false;
        for(int j=0;j<n-i-1;j++){
            if(a[j]>a[j+1]){
                swap(a[j],a[j+1]);
                swapped=true;
            }
        }
        if(!swapped) break;
    }
}
```

适用：教学/理解，不建议实战。

### 选择排序 Selection Sort

思路：每一轮选最小值放到当前位置。

- 时间：O(n²)
- 空间：O(1)
- 稳定：不稳定（会跨位置交换）

```cpp
void selectionSort(vector<int>& a){
    int n=a.size();
    for(int i=0;i<n;i++){
        int minPos=i;
        for(int j=i+1;j<n;j++){
            if(a[j]<a[minPos]) minPos=j;
        }
        swap(a[i], a[minPos]);
    }
}
```

### 插入排序 Insertion Sort

思路：维护前面一段有序，把当前元素插到正确位置（像打扑克牌插牌）。

- 平均/最坏：O(n²)
- 最好（几乎有序）：O(n)
- 空间：O(1)
- 稳定：稳定

```cpp
void insertionSort(vector<int>& a){
    int n=a.size();
    for(int i=1;i<n;i++){
        int key=a[i];
        int j=i-1;
        while(j>=0 && a[j]>key){
            a[j+1]=a[j];
            j--;
        }
        a[j+1]=key;
    }
}
```

适用：数据规模小、或数据“近乎有序”；也是很多高级排序的小规模优化段。

### 快速排序

**算法思想**

快速排序使用 **分治思想（Divide and Conquer）**：

步骤：

1. 选择一个元素作为 **pivot（基准值）**
2. 把数组重新排列：
   - 小于 pivot 的放左边
   - 大于 pivot 的放右边
3. 对左右子数组递归执行同样操作

核心过程叫：

```cpp
partition（划分）
```

经典排序

```cpp
void quickSort(vector<int>& a, int l, int r)
{
    if(l >= r) return;

    int i = l;
    int j = r;
    int pivot = a[l];

    while(i < j)
    {
        while(i < j && a[j] >= pivot) j--;//参照左移
        while(i < j && a[i] <= pivot) i++; 

        swap(a[i], a[j]);
    }

    swap(a[l], a[i]);

    quickSort(a, l, i-1);
    quickSort(a, i+1, r);
}
```

| 情况 | 复杂度     |
| ---- | ---------- |
| 最好 | O(n log n) |
| 平均 | O(n log n) |
| 最坏 | O(n²)      |

### 归并排序

归并排序做三件事：

```cpp
1 分解 (Divide)
2 递归排序 (Conquer)
3 合并 (Merge)
```

流程：

```cpp
mergeSort(arr):
    分成左右两半
    mergeSort(left)
    mergeSort(right)
    merge(left,right)
```

```cpp
void merge(vector<int>& a, int l, int mid, int r)
{
    vector<int> temp;

    int i = l;
    int j = mid + 1;

    while(i <= mid && j <= r)
    {
        if(a[i] <= a[j])
        {
            temp.push_back(a[i]);
            i++;
        }
        else
        {
            temp.push_back(a[j]);
            j++;
        }
    }

    while(i <= mid)
    {
        temp.push_back(a[i]);
        i++;
    }

    while(j <= r)
    {
        temp.push_back(a[j]);
        j++;
    }

    for(int k = 0; k < temp.size(); k++)
    {
        a[l + k] = temp[k];
    }
}

void mergeSort(vector<int>& a, int l, int r)
{
    if(l >= r) return;

    int mid = (l + r) / 2;

    mergeSort(a, l, mid);
    mergeSort(a, mid + 1, r);

    merge(a, l, mid, r);
}

mergeSort(nums,0,nums.size()-1);
```

关键点：

**合并两个有序数组**

## 注意

- `unordered_map` 是无序的，`sort` 才能保证顺序
- 自定义比较函数用 `<`，不要写 `<=`
- `sort` 需要随机访问迭代器（`list` 不能用 `sort(v.begin(), v.end())`，`list` 有自己的 `list.sort()`）
