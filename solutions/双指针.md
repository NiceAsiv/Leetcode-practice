# 双指针

双指针就是：

> **用两个指针在数组/字符串上移动，减少重复扫描。**

最典型形式：

```cpp
int left = 0;
int right = n - 1;

while (left < right) {
    // 根据条件移动指针
}
```

或者

```cpp
int slow = 0;
for (int fast = 0; fast < n; fast++) {
}
```

## 双指针有四大经典类型

### 1️⃣ 对撞双指针（Two Ends）

从数组两端往中间移动。

### 模板

```cpp
int left = 0;
int right = n - 1;

while (left < right) {
    if (condition) {
        left++;
    } else {
        right--;
    }
}
```

### 典型题

Two Sum II

```
while (l < r) {
    int sum = nums[l] + nums[r];

    if (sum == target) return {l, r};
    else if (sum < target) l++;
    else r--;
}
```

因为数组有序。

### 2️⃣ 快慢指针（Fast Slow）

两个指针从同一个方向移动。

### 模板

```
int slow = 0;

for (int fast = 0; fast < n; fast++) {
    if (condition) {
        nums[slow] = nums[fast];
        slow++;
    }
}
```

### 经典题

Remove Duplicates from Sorted Array

```
if (nums[fast] != nums[fast-1]) {
    nums[slow] = nums[fast];
    slow++;
}
```

### 3️⃣ 滑动窗口（Sliding Window）

这是双指针里**最重要的一类**。

两个指针形成一个窗口：

```
[left ...... right]
```

窗口会：

- 扩大
- 收缩

### 模板

```
int left = 0;

for (int right = 0; right < n; right++) {

    while (窗口不合法) {
        left++;
    }

}
```

### 典型题

Longest Substring Without Repeating Characters

### 4️⃣ 同向双指针（Merge 类）

两个数组一起扫描。

### 模板

```
while (i < n && j < m) {
    if (a[i] < b[j]) i++;
    else j++;
}
```

典型题：

Merge Sorted Array

## 案例

### 283. 移动零

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意** ，必须在不复制数组的情况下原地对数组进行操作。

**示例 1:**

```
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]
```

**示例 2:**

```
输入: nums = [0]
输出: [0]
```

**提示**:

- `1 <= nums.length <= 104`
- `-231 <= nums[i] <= 231 - 1`

常规思路

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        vector<int> ans;
        for(int x: nums)
        {
            if(x!=0) ans.push_back(x);

        }
        while(ans.size()<nums.size()) ans.push_back(0);
        nums = ans;

    }
};
```

快慢指针思路

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int slow = 0;

        for (int fast = 0; fast < nums.size(); fast++) {
            if (nums[fast] != 0) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        while (slow < nums.size()) {
            nums[slow] = 0;
            slow++;
        }
    }
};
```

### [11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)

给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

提示：要想到其实从宽最大开始往里找

**说明：**你不能倾斜容器。

 

**示例 1：**

![img](https://aliyun-lc-upload.oss-cn-hangzhou.aliyuncs.com/aliyun-lc-upload/uploads/2018/07/25/question_11.jpg)

```
输入：[1,8,6,2,5,4,8,3,7]
输出：49 
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。
```

**示例 2：**

```
输入：height = [1,1]
输出：1
```

 双指针真的牛

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int left = 0;
        int right = height.size()-1;
        int max_amount =0;

        while(left<right){            
            int amount = (right - left)*min(height[right],height[left]);
            max_amount = max(amount,max_amount);
            if(height[left]<height[right]) left ++;
            else right --;
        }
        return max_amount;
    }
};
```

### 42. 接雨水

思路1暴力扫描左右的最大值，当前位置的接水量 = 较短的高度【左右包括自身的高度】 - 自身高度

假设：

```
leftMax = 7
rightMax = 4
```

结构：

```
7      4
|      |
|  i   |
|      |
```

水最多只能到 **4**，因为右边只有 4。

如果水超过 4：

```
7      4
|~~~~~~|
|~~~~~~|
|  i   |
```

水会从右边溢出去。

所以：

```
水位 = min(leftMax, rightMax)
```

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        // if(height.size() == 0) return 0;
        int weight = 0;
        for(int i =1; i< height.size()-1; i++){
            int leftH =0, rightH = 0;
            
            
            //left 
            for(int j=i; j>=0 ;j--){
                leftH = max(leftH, height[j]);
            }

            //right
            for(int j=i; j<height.size();j++){
                rightH = max(rightH,height[j]);
            }
            
            int minone = min(leftH,rightH);

            weight = weight + (minone -height[i]);
        }
        return weight;
    }
};
```

#### 优化

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        // if(height.size() == 0) return 0;
        int weight = 0;
        int leftMax =0, rightMax =0;
        int left = 0 ,right = height.size() -1;
        while(left<right){
            leftMax = max(leftMax,height[left]);
            rightMax = max(rightMax,height[right]);
            if(leftMax<rightMax){
                weight = weight + leftMax - height[left];
                left++;
            }else{
                weight = weight + rightMax - height[right];
                right--;
            }
        }
        return weight;
    }
};
```



```
water[i] = min(leftMax, rightMax) - height[i]
```

但双指针不需要真的对每个位置都重新计算左右最大值。

leftMax = max(leftMax, height[left]);

rightMax = max(rightMax, height[right]);

右边真实最大值 > rightMax

左边真实最大值 > leftMax

关键结论：

- 如果 `leftMax < rightMax`，那么当前位置 `left` 的接水量只取决于 `leftMax`
- 因为右边一定存在一个更高的挡板（至少是 `rightMax`），此时短板是左边
- 所以可以直接计算 `left` 位置的水量，然后移动 `left`

## 什么时候想到双指针？

看到这些关键词就要警觉：

### 1️⃣ 数组 **有序**

比如：

```
sorted
increasing
non-decreasing
```

基本可以用双指针。

### 2️⃣ 子数组 / 子字符串

比如：

```
longest substring
minimum window
subarray
```

通常是 **滑动窗口**。

### 3️⃣ 删除元素 / 压缩数组

比如：

```
remove
deduplicate
move zero
```

通常是 **快慢指针**。

### 4️⃣ 两数关系

比如：

```
two sum
three sum
closest
```

通常是 **对撞指针**。
