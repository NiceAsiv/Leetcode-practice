# 图论

图论是算法题中非常重要的一类问题。很多看似不同的问题，本质上都可以转化为 **图的遍历或路径问题**。在 LeetCode 中，图论题目通常围绕 **DFS、BFS、最短路径、拓扑排序、并查集** 等核心算法展开。

## 一、图的基本概念

图（Graph）由 **顶点（Vertex）** 和 **边（Edge）** 组成。

一个图通常表示为：

```cpp
G = (V, E)
```

其中：

```cpp
V = 顶点集合
E = 边集合
```

常见图的类型包括：

无向图：边没有方向，例如：

```cpp
A -- B
```

有向图：边有方向，例如：

```
A → B
```

带权图：边有权值，例如：

```
A --(3)--> B
```

## 二、图的存储方式

在算法题中，图通常使用两种方式存储。

### 邻接矩阵

用二维数组表示节点之间是否相连。

例如：

```
0 1 0
1 0 1
0 1 0
```

含义是：

```
节点0连接节点1
节点1连接节点2
```

优点：

```
查询是否存在边 O(1)
```

缺点：

```
空间 O(n²)
```

一般很少在 LeetCode 使用。

### 邻接表

最常见方式。

例如：

```bash
0: 1 2
1: 2
2: 3
3: 1
节点0连接节点1和2
节点1连接节点0和3
节点2连接节点0
节点3连接节点1
```

C++常见写法：

```cpp
vector<vector<int>> graph(n);
```

添加边：

```cpp
graph[u].push_back(v);
```

优点：

```
空间 O(V + E)
```

大多数题都使用邻接表。

## 三、图的遍历

图的遍历是图论最基础的操作，类似树的遍历。

主要有两种：

```
DFS
BFS
```

### DFS（深度优先搜索）

DFS 的思想是：

```
一条路走到黑
```

先访问当前节点，然后递归访问邻居。

示例代码：

```cpp
void dfs(int node, vector<vector<int>>& graph, vector<bool>& visited) {

    visited[node] = true;

    for(int next : graph[node]) {
        if(!visited[next]) {
            dfs(next, graph, visited);
        }
    }
}
```

DFS 常见应用：

- 判断连通性

- 岛屿问题
- 拓扑排序
- 回溯搜索

典型题：

```
200 Number of Islands
695 Max Area of Island
547 Number of Provinces
```

### BFS（广度优先搜索）

BFS 的思想是：

```
一层一层扩展
```

通常使用 **队列** 实现。

代码示例：

```cpp
void bfs(int start, vector<vector<int>>& graph) {

    queue<int> q;
    vector<bool> visited(graph.size(), false);

    q.push(start);
    visited[start] = true;

    while(!q.empty()) {

        int node = q.front();
        q.pop();

        for(int next : graph[node]) {
            if(!visited[next]) {
                visited[next] = true;
                q.push(next);
            }
        }
    }
}
```

算法逻辑：

```bash
1 创建队列 queue
2 创建 visited 数组
3 将起点加入队列
4 标记起点为已访问
5 当队列不为空时：
    取出队首节点
    遍历它的所有邻居
    如果邻居未访问：
        标记访问
        加入队列
```

BFS 常见用途：

- 最短路径（无权图）
- 层级遍历
- 扩散问题

典型题：

```
127 Word Ladder
994 Rotting Oranges
752 Open the Lock
```

####  Dijkstra（带权图）

每次选当前距离最小的节点扩展

```cpp
vector<int> dijkstra(int n, vector<vector<pair<int,int>>>& graph, int start){

    vector<int> dist(n, INT_MAX);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;

    dist[start] = 0;
    pq.push({0,start});

    while(!pq.empty()){

        auto [d,u] = pq.top();
        pq.pop();

        if(d > dist[u]) continue;

        for(auto [v,w] : graph[u]){

            if(dist[v] > dist[u] + w){

                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }

    return dist;
}
```

```cpp
class UnionFind{
public:

    vector<int> parent;

    UnionFind(int n){

        parent.resize(n);

        for(int i=0;i<n;i++)
            parent[i] = i;
    }

    int find(int x){

        if(parent[x] != x)
            parent[x] = find(parent[x]);

        return parent[x];
    }

    void unite(int x,int y){

        parent[find(x)] = find(y);
    }
};
```

```cpp
void dfs(vector<vector<char>>& grid, int r, int c){
```
