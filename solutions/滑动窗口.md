# 滑动窗口

滑动窗口（Sliding Window）是处理 **连续子数组、连续子串** 问题的常见算法。

它使用两个指针：

```cpp
left
right
```

维护一个连续区间：

```text
[left, right]
```

核心思想：

```text
right 负责扩大窗口
left 负责缩小窗口
```

很多暴力枚举所有连续区间需要：

```text
O(n²)
```

而滑动窗口通常可以优化到：

```text
O(n)
```

因为 `left` 和 `right` 都只向右移动一次。

------

## 一、基本思想

例如：

```text
[1, 2, 3, 4, 5]
```

当前窗口：

```text
1 [2 3 4] 5
   ↑   ↑
 left right
```

`right` 向右移动：

```text
1 [2 3 4 5]
   ↑     ↑
 left   right
```

窗口扩大。

如果窗口不满足条件，就移动 `left`：

```text
1 2 [3 4 5]
     ↑   ↑
   left right
```

因此滑动窗口的核心流程：

```text
扩大窗口
   ↓
判断窗口是否合法
   ↓
不合法 → 缩小窗口
   ↓
更新答案
```

看到这些关键词可以考虑：


## 三、固定长度窗口

例如：

> 求长度为 `k` 的连续子数组最大和。

窗口长度始终保持：

```cpp
right - left + 1 == k
```

模板：

```cpp
int left = 0;
int sum = 0;

for(int right = 0; right < nums.size(); right++){

    sum += nums[right];

    if(right - left + 1 > k){
        sum -= nums[left];
        left++;
    }

    if(right - left + 1 == k){
        // 更新答案
    }
}
```

核心：

```text
右边加入一个
左边删除一个
窗口整体向右移动
```

典型题：

```text
643 Maximum Average Subarray I
438 Find All Anagrams in a String
```



#### [438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

中等

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**示例 1:**

```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```

 **示例 2:**

```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```

**提示:**

- `1 <= s.length, p.length <= 3 * 104`
- `s` 和 `p` 仅包含小写字母

**solutions**

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        int sLen = s.size(), pLen = p.size();

        if(pLen > sLen){
            return vector<int>();
        }

        vector<int> ans;

        vector<int> need(26,0);
        vector<int> window(26,0);
        for(char c: p){
            need[c-'a'] ++;
        }
        
        int left = 0;

        for(int right=0; right< s.size(); right++){
            window[s[right] - 'a']++;

            if(right - left + 1 > pLen){
                window[s[left] - 'a']--;
                left++;
            }

            //检查窗口与目标的p 只需要数量一致就行
            if(right -left + 1 == pLen && window == need){
                ans.push_back(left);
            }
        }
        return ans;
    }
};
```



## 四、可变长度窗口

更常见的滑动窗口形式：

```cpp
int left = 0;

for(int right = 0; right < n; right++){

    // right 加入窗口

    while(窗口不满足条件){

        // left 移出窗口
        left++;
    }

    // 更新答案
}
```

一句话理解：

```text
right 不断扩大窗口
出现问题时 left 往右收缩
```

## 五、最长窗口

例如：

```text
最长无重复子串
```

要求：

```text
窗口始终合法
在合法情况下尽可能大
```

模板：

```cpp
int left = 0;
int ans = 0;

for(int right = 0; right < n; right++){

    // 加入 right

    while(窗口不合法){

        // 删除 left
        left++;
    }

    ans = max(ans, right - left + 1);
}
```

### 最长无重复子串

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {

        unordered_map<char,int> count;

        int left = 0;
        int ans = 0;

        for(int right = 0; right < s.size(); right++){

            count[s[right]]++;

            while(count[s[right]] > 1){

                count[s[left]]--;
                left++;
            }

            ans = max(ans, right - left + 1);
        }

        return ans;
    }
};
```

逻辑：

```text
加入字符
   ↓
出现重复？
   ↓
移动 left 删除字符
   ↓
恢复合法
   ↓
更新最长长度
```

## 六、最短窗口

例如：

> 找到和大于等于 target 的最短连续子数组。

LeetCode 209：

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {

        int left = 0;
        int sum = 0;
        int ans = INT_MAX;

        for(int right = 0; right < nums.size(); right++){

            sum += nums[right];

            while(sum >= target){

                ans = min(ans, right - left + 1);

                sum -= nums[left];
                left++;
            }
        }

        return ans == INT_MAX ? 0 : ans;
    }
};
```

核心：

```text
窗口满足条件
      ↓
先记录答案
      ↓
继续缩小窗口
      ↓
寻找更短答案
```

------

## 七、最长和最短的区别

### 最长问题

```cpp
while(窗口不合法){
    left++;
}

ans = max(ans, right-left+1);
```

也就是：

```text
不合法 → 缩
合法 → 更新最长
```

### 最短问题

```cpp
while(窗口合法){

    ans = min(ans, right-left+1);

    left++;
}
```

也就是：

```text
合法 → 更新答案
     → 继续缩小
```

## 八、滑动窗口常见状态

窗口中通常维护这些信息：

### 窗口长度

```cpp
right - left + 1
```

### 窗口和

```cpp
sum += nums[right];
sum -= nums[left];
```

### 字符出现次数

```cpp
unordered_map<char,int> count;
```

或者：

```cpp
vector<int> count(26);
```

常用于：

```text
重复字符
字符种类
异位词
最小覆盖子串
```

## 九、通用模板

滑动窗口最重要的模板：

```cpp
int left = 0;

for(int right = 0; right < n; right++){

    // 1. right 进入窗口
    add(nums[right]);

    // 2. 判断是否需要缩小
    while(窗口不合法){

        // 3. left 离开窗口
        remove(nums[left]);

        left++;
    }

    // 4. 更新答案
}
```

做题时主要考虑三个问题：

```text
right 加进来以后维护什么？

什么时候移动 left？

什么时候更新答案？
```

## 十、滑动窗口套路总结

```text
是不是连续子数组 / 子串？
          ↓
         是
          ↓
窗口长度固定？
    ↓          ↓
   是          否
    ↓           ↓
固定窗口     可变窗口
                ↓
          最长还是最短？
           ↓        ↓
         最长      最短
           ↓        ↓
       不合法就缩   合法就缩
```

常见题目：

```text
643 固定长度窗口
209 最短窗口
3   最长无重复子串
904 最多 K 种元素
438 字母异位词
76  最小覆盖子串
```

滑动窗口可以记成一句话：

```text
right 负责扩张，
left 负责收缩，
窗口负责维护状态。
```
