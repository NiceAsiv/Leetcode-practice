# 动态规划

动态规划（Dynamic Programming，简称 DP）是一种**把复杂问题拆分成更小的子问题，并把子问题的结果保存下来，避免重复计算**的算法思想。

## 基础概念

### 为什么需要动态规划

举个经典例子：

### 斐波那契数列

$$
F(n) = F(n-1) + F(n-2)
$$

如果用普通递归：

```cpp
int fib(int n){
    if(n <= 1) return n;
    return fib(n-1) + fib(n-2);
}
```

问题是：

fib(5) 会算 fib(4) 和 fib(3), fib(4) 又会算 fib(3) 和 fib(2), fib(3) 被算了很多次

这叫 **重复子问题**。

如果使用动态规划,每个值只算一次，时间复杂度从指数级变成线性级。

```c++
int fib(int n){
    vector<int> dp(n+1);
    dp[0] = 0;
    dp[1] = 1;

    for(int i = 2; i <= n; i++){
        dp[i] = dp[i-1] + dp[i-2];
    }

    return dp[n];
}
```
