# 动态规划

动态规划（Dynamic Programming，简称 DP）是一种**把复杂问题拆分成更小的子问题，并把子问题的结果保存下来，避免重复计算**的算法思想。

## 基础概念

### 为什么需要动态规划

动态规划通常用于解决：

```text
最优解问题
```

例如：

- 最大值
- 最小值
- 方案数
- 可行性判断

动态规划的核心是三个步骤：

```
1. 定义状态
2. 写出状态转移方程
3. 确定初始条件
```

简单理解就是：

```text
当前问题 = 更小子问题的组合
```

例如经典问题：

斐波那契数列

```
f(n) = f(n-1) + f(n-2)
```

如果用递归：

```cpp
int fib(int n){
    if(n<=1) return n;
    return fib(n-1)+fib(n-2);
}
```

会产生大量重复计算。

动态规划的做法是：

```cpp
int fib(int n) {
    vector<int> dp(n+1);

    dp[0] = 0;
    dp[1] = 1;

    for(int i=2;i<=n;i++){
        dp[i] = dp[i-1] + dp[i-2];
    }

    return dp[n];
}
```

时间复杂度从：

```
O(2^n)
```

降低到：

```
O(n)
```


举个经典例子：

### 斐波那契数列

$$
F(n) = F(n-1) + F(n-2)
$$

如果用普通递归：

```cpp
int fib(int n){
    if(n <= 1) return n;
    return fib(n-1) + fib(n-2);
}
```

问题是：

fib(5) 会算 fib(4) 和 fib(3), fib(4) 又会算 fib(3) 和 fib(2), fib(3) 被算了很多次

这叫 **重复子问题**。

如果使用动态规划,每个值只算一次，时间复杂度从指数级变成线性级。

```c++
int fib(int n){
    vector<int> dp(n+1);
    dp[0] = 0;
    dp[1] = 1;

    for(int i = 2; i <= n; i++){
        dp[i] = dp[i-1] + dp[i-2];
    }

    return dp[n];
}
```

## 方法

1. 确定dp[i]的含义，第i个斐波那契数
2. 确定递推公式：dp[i] = dp[i-1] + dp[i-2];
3. 如何初始化：dp[0] =1 dp[1]=1
4. 遍历顺序 从前往后遍历
5. 打印dp树

### 爬楼梯

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

分析：

1阶方法 1种方法

2阶方法 2种方法

3阶方法 3种方法

4阶犯法  5种方法

含义：dp[i]表示达到台阶i有多少种方法

转移公式：dp[i] = dp[i-2] + dp[i-1]

初始化：dp[1] =1

dp[2] =2 

遍历顺序：从前往后

重点是在发现爬楼的规律

```cpp
class Solution {
public:
    int climbStairs(int n) {
        vector<int> dp(n+1);
        if(n==1) return 1;
        if(n==2) return 2;
        dp[1] =1; 
        dp[2] =2;
        for(int i =3;i<=n;i++){
            dp[i] = dp[i-1] +dp[i-2];
        }
        return dp[n];
    }
};
```

### [62. 不同路径](https://leetcode.cn/problems/unique-paths/)

```
dp[i][j]表示到达i*j格子有多少种走法
```

因为只能往下或者往右走，那么到达

```
dp[i][j] = dp[i][j-1] +dp[i-1][j]
```

开始初始化

```
dp[0][0] = 0
dp[i][0] = 1;
dp[0][j] = 1;
```

遍历方式：从左往右，从上到下

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m, vector<int>(n));
        //初始化dp[0][j]
        for(int i =0;i<m;i++){
            dp[i][0] =1;
        }
        for(int j =1;j<n;j++){
            dp[0][j] =1;
        }
        for(int i = 1; i<m; i++)
         {
            for(int j =1; j<n; j++){
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
            }
         }
         return dp[m-1][n-1];
    }
};
```
